# Spanish Glossary Decisions for teg-blue.org

Status: Step 1 draft for review. `/es/glossary` now applies these decisions in
real page copy for review.

Last audited: 2026-07-08.
Last implementation update: 2026-07-09.

This glossary is for `teg-blue.org`, the research and practitioner-facing
framework site. It should stay clear, source-aware, non-diagnostic, and
non-moralizing. Compared with the `teg-blue.com` glossary, `.org` can use more
formal research language, but it should still remain readable and behavior-first.

## Voice Rules

- Translate meaning, not English sentence structure.
- Keep project names stable unless Anna explicitly approves translated brand
  names.
- Use Spanish that can work across Spain/global Spanish without sounding overly
  clinical or institutional.
- Keep mechanism, impact, capacity, and response separate.
- Keep claims modest: source support, TEG-Blue integration, public explanation,
  applied use, and open questions should not collapse into one another.
- Prefer verbs when direct nouns become heavy: `hacer visible`, `volver a
  discutir`, `mantener separado`, `nombrar el impacto`.
- Do not turn patterns into diagnoses, identities, or person-verdicts.
- When English copy uses defensive negation, consider rewriting in Spanish as a
  positive boundary: what the map can do, what it cannot establish, and what
  response remains needed.

  home map or exposing any Spanish route publicly.

  Spanish terms.

- `power mobilisation`: decide whether `poder` or `fuerza` carries the intended
  mechanism without moralizing.

  positive or business-like in the actual map copy.

  person judgment.
- Long UI labels in the home Gradient need mobile QA before launch.

## Current Page Decisions Applied In `/es/glossary`

- `/es/glossary` is now a simple first-reader glossary, not a full technical
  terminology reference. Keep it short and emotionally safe: core names, map
  orientation, patterns, capacity, regulation, repair, and pattern reading.
- Formal framework name stays `The Emotional Gradient Blueprint`, with Spanish
  descriptive copy around it.
- Central map display name uses `El Gradiente del Sistema Nervioso`.
- Engine names stay in English when they appear elsewhere: `TEG-Blue Engine`,
  `Deep Engine`, and `Visible Engine`. They are parked from the simple glossary
  for now.
- `Formation / Formación` remains an open decision for Engine/provenance copy,
  but is parked from the simple glossary.
- `Actual Conditions` can render as `condiciones reales` in technical or method
  copy, but is parked from the simple glossary.
- `state-shaped perception` is parked from the first glossary slice. When used
  in methodology or article context, it should render as `percepción modulada
  por el estado`.
- `emotional-pattern legibility` can render as `legibilidad de patrones
  emocionales`, with body copy also using the verb frame `hacer visibles`, but
  the simple glossary currently uses `patrones emocionales`.
- `claim status` should be handled as `alcance de la afirmación` or
  `tipo de afirmación`, depending on sentence context.
