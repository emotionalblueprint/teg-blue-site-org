# Spanish Terminology Style Guide

## Register

Use neutral international Spanish: precise, calm, research-grounded, and readable. Prefer clear explanatory phrasing over literal translation when an English term carries framework meaning.

## Style Rules

- Do not translate framework IDs or URL slugs in v1.
- Keep scientific names, cited authors, and model codes unchanged.
- Avoid moral labels. Prefer "el sistema se organiza..." over "la persona es...".
- Use "el sistema nervioso" when the mechanism matters; use "el cuerpo" when the sentence is about felt biological reading.
- Avoid over-promising validation. Keep the distinction between source traces, grounding, and clinical validation.
