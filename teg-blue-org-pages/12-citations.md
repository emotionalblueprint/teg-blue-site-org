# How to Cite

Please cite TEG-Blue research using the formats below. All publications are licensed under CC-BY-NC-SA-4.0.

---

## Citing the TEG-Blue Framework

When referencing the TEG-Blue framework in general (not a specific publication):

**APA 7th Edition:**
Paretas-Artacho, A. (2026). TEG-Blue: The Emotional Gradient Framework. https://teg-blue.org

**BibTeX:**
```
@misc{tegblue2026,
  author = {Paretas-Artacho, Anna},
  title = {TEG-Blue: The Emotional Gradient Framework},
  year = {2026},
  url = {https://teg-blue.org}
}
```

---

## Citing the Validation Study

**APA 7th Edition:**
Paretas-Artacho, A. (2026). Validation Study: Four-Mode Gradient in Natural Language. TEG-Blue Research. https://doi.org/10.5281/zenodo.18428907

**BibTeX:**
```
@article{tegblue_validation_2026,
  author = {Paretas-Artacho, Anna},
  title = {Validation Study: Four-Mode Gradient in Natural Language},
  year = {2026},
  publisher = {TEG-Blue Research},
  doi = {10.5281/zenodo.18428907},
  url = {https://doi.org/10.5281/zenodo.18428907}
}
```

---

## Attribution for independent work

Independent research that builds on TEG-Blue should cite the framework as the originating architecture. If you are unsure how to attribute, contact **research@teg-blue.org**.
